# 自检清单
一、你想“做给谁玩”

这个游戏是 主要做给谁玩 的？

玩家一次游玩大概多久你最能接受？

玩家是“随便玩玩”还是“认真投入”？

二、玩家在游戏里“主要做什么”

玩家在游戏中 反复做的一件事是什么？

玩家做这件事时，是更偏 操作 还是 思考？

玩家失败时，你更希望他们觉得：

是不是自己操作的问题？

还是决策和选择的问题？

三、你希望玩家“感受到什么”

玩家玩完一局后，最该留下的情绪是什么？

你是更想让玩家感到：

紧张

放松

成就感

沉浸

思考

你希望玩家是“赢了很爽”，还是“过程很有意思”？

四、游戏类型自然浮现

这个游戏 更适合回合制还是即时制？

这个游戏如果不能有战斗，还能成立吗？

如果砍掉剧情，玩法还能站住吗？

如果砍掉玩法，只剩叙事，还想玩吗？

五、主题来源（非常关键）

你最近 最常反复想到的一个话题/情绪/问题 是什么？

你有没有一个 一直想表达、但没合适方式说出口的东西？

如果这个游戏只能围绕一个词展开，那会是哪个词？

六、世界观聚焦

你更想讲的是：

个体的故事，还是

世界/时代的故事？

故事规模更像：

一次事件

一段旅程

一生

这个世界是更接近现实，还是明显幻想？

七、主题与玩法绑定

如果把主题抽象成一种行为，那是什么行为？

玩家“做的事”和“你想说的主题”是否是一件事？

玩家每一次行动，是否都在强化主题？

八、最终收敛（强制选择）

如果只能选一个作为核心，你选：

玩法

主题

你更能接受：

玩法普通但主题明确

玩法强但主题模糊

你希望别人如何一句话记住你的游戏？

九、方向锁定

用一句话描述你的游戏：

这是一个关于 __________ 的游戏，玩家通过 __________ 来体验它。

如果这个游戏 只能做 1 个月，它还能成立吗？

如果答案是否定的，你最先该砍掉的是什么？
