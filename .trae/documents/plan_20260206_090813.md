# 重构战斗逻辑与UI设计方案

根据你的要求，我将对战斗系统的核心逻辑和UI进行以下重构：

## 1. 战斗核心逻辑 (BattleManager)

### 真气系统 (Energy)

* **最大真气值**: 调整为 **10** 点。

* **回复机制**: 每次玩家回合开始时，获得 **3** 点真气（采用累积制，上限10点，保留上回合未使用的真气）。

### 抽牌与手牌 (Draw & Hand)

* **开局抽牌**: 战斗开始时抽取 **5** 张牌。

* **回合抽牌**: 后续每回合开始时抽取 **2** 张牌。

* **手牌上限**: 回合结束时，不再清空手牌。如果手牌数超过 **8** 张，将自动丢弃多余的卡牌（优先丢弃最左侧的牌）。

## 2. 经脉系统 UI (Meridian UI)

* **效果显示**: 修改经脉槽位 (`MeridianSlot`)，使用不同颜色的方块来代表内功效果，代替原本的卡牌图标。

  * 🔴 **红色方块**: 攻击型内功

  * 🔵 **蓝色方块**: 防御型内功

  * 🟣 **紫色方块**: 辅助/特殊内功

* **结算时机**: 保持在回合结束时结算（符合现有逻辑）。

## 3. 状态 UI (Status UI)

* **图标化显示**: 创建新的 `StatusIcon` 组件，替代纯文本显示。

* **集成**: 在角色面板 (`CharacterPanel`) 下方动态生成状态图标，清晰展示正面/负面状态及其层数。

## 4. 界面布局 (Layout)

* **真气 UI 迁移**: 将真气球 (`EnergyOrb`) 从顶部栏移动到手牌区域的中上方，使其更靠近玩家的操作视线。
