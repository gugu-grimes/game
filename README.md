
把“卡组对抗+路径随机+卡牌池成长”作为骨架；在每场战斗中加入“场上单位（同游戏王的怪兽场）”、可触发的**属性检定/豁免（受DND启发）**与**战技组合/祭品/合体**机制，让每张卡既能作一次性技能，也可以作为“技法材料”在场上生成持久伙伴或转换为更强技法。风格上用“内力（气）/心法/门派绝学/武学招式”来替代魔法/怪兽概念，贴合武侠。

# 1) 角色与属性（DnD 风格简化）

玩家角色有 6 项基础属性（作用略同 DnD）：

* 力量 STR（武技伤害、祭品/破甲）
* 敏捷 DEX（先攻、闪避、反击）
* 体质 CON（生命上限、恢复）
* 智力 INT（心法强度、解密/阵法）
* 感知 WIS（察觉陷阱/看穿伪装、反制）
* 魅力 CHA（招募NPC、控制/劝降技）

这些属性会影响**检定（skill checks）**和某些卡的等级化数值。每个角色初始点分配由职业/门派给定（例如“剑宗偏 STR/DEX”，“内功门偏 CON/INT/WIS”）。

属性的数值会直接影响一些卡牌数值（例如：一张名为“破山式”的卡：基础伤害 8 + STR×0.5）。

# 2) 回合结构（武侠版：准备→行动→反制→收束）

把回合分成明确阶段，方便加入反应/机会动作：

1. **准备阶段（Tactics）**

   * 选择“战术姿态”（进攻 / 防守 / 机动 / 破招），每种姿态给本回合不同的增益（例如：进攻+伤害，防守+格挡，机动+先攻概率，破招+对方豁免判定降低）。
   * 可把 0-cost 的“布局卡/阵法卡”在此阶段上场（如果卡带有“布阵”标签）。

2. **召唤/布阵阶段（Summon/Deploy）**

   * 把“伴侣/武学残页/阵眼”类卡放到场上成为持续单位（类似游戏王怪兽），有生命值和攻击值，存在固定格子（默认最多 3——可升级）。
   * 场上单位会在行动阶段作为额外攻击来源或提供被动 Buff。

3. **行动阶段（Main）**

   * 玩家按能量（Qi，通常 3~4 点/回合）打出卡牌。卡牌分为：攻击、技巧（技能/法术）、反应（瞬发）、召唤、心法（持续power）、消耗（一次性强力）。
   * 某些卡会触发 **属性检定**（见下一节）。

4. **反制/机会阶段（Reaction）**

   * 敌方可发动“反应/连环招”，玩家和伙伴也可使用“反应点”（Reaction Points，默认每回合 1 点）来做瞬发（如闪避、格挡反击、解招）。反应有冷却，消耗有限资源。

5. **收束阶段（End）**

   * 持续效果结算，逐回合伤害/恢复生效，检定失败的后果触发等。

# 3) 属性检定 / DnD 元素的引入（如何融合在战斗里）

* **什么时候触发检定？**：卡牌文本标注“需 WIS 检定”、“对方 STR 豁免”，或战术/遭遇事件（例如冲阵需要 DEX 检定躲避陷阱）。
* **检定公式（简化）**：roll 1d20 + 属性修正（例如属性 14 → +2）对抗 DC（难度）。
* **优势/劣势（Adv/Dis）**：来自姿态/装备/场上单位。例如处于“机动”姿态对 DEX 检定获得优势（投两次，取高）。
* **豁免与抵抗**：敌人或玩家的豁免值基于敌我属性与等级。豁免成功可减少或避免效果（例如减半伤害或免疫眩晕）。
* **失败后果**：失败可能造成“拘束/破招/失去回合”等强烈后果，使检定具有高赌注感，贴近 DnD 的戏剧性。

> 设计提示：把检定用作“高风险高回报”和“叙事决定点”。例如用“唬对手一招”扳回牌桌时，需要一次 CHA 检定成功才能让敌人失去反应。

# 4) 游戏王式场上单位与召唤系统（Wuxia 化）

* **单位（Companions / 招式化身）**：卡牌可以“召唤”为场上单位（称“门徒/妖兽/剑影/招式残像”）。单位属性：生命、攻击、持续效果、耗费（上场时消耗 Qi 或牺牲卡片）。
* **场格与位置**：3 个前排格（造成伤害的主要来源）和 1 个后排（提供支援、心法增益）。敌我单位位置会影响技能目标（如“横斩只会攻击前排单位/角色”）。
* **祭品 / 升阶（Tribute / Fusion）**：牺牲 1~2 个场上单位或手牌可以召唤“绝学”或“合体招式”（更强的技法），类似游戏王的祭品或融合机制。
* **场上持久性**：单位存在至被击破或被特定卡回收，某些单位会在死亡时触发效果（如“临终一击：为主角恢复 3 气”）。

# 5) 卡牌类型与关键词（建议卡池结构）

卡池分层（基础 / 精英 / 绝学/秘籍） + 关键词：

1. **普通攻击卡（Attack）**：即时伤害，可能带弱化。例：破剑 6 伤害，消耗 1 Qi。
2. **防御/格挡卡（Block）**：吸收伤害。例：拦挡（Gain 12 Block）消耗 1 Qi。
3. **技巧卡（Skill）**：触发检定、位移或控场。例：偷袭（进行 DEX 检定，成功则先攻并造成额外 8 点伤害）。
4. **心法卡（Power）**：持续效果直到战斗结束。例：内劲·回风（每回合开始回复 2 HP）。
5. **召唤卡（Summon）**：把卡转为场上单位。例：剑影（Summon：剑影，HP 6 / ATK 4）。
6. **消耗卡（Expend / One-shot ultimate）**：一次性强力，使用后从牌组剔除。适合作为“绝招”。
7. **阵法/装备卡（Relic-like / Artifact）**：可在营地或商店购入，提供长期被动。
8. **反应卡（Reaction）**：瞬发，消耗 Reaction Points，可在敌人回合中使用。

常用关键词：布阵（Set）、祭献（Tribute）、合体（Merge）、破招（Break）、连击（Combo）、护佑（Ward）、反击（Riposte）、蓄力（Charge）等。

# 6) 资源与行动经济

* **Qi（气）**：每回合基础 3 点，可由心法或装备+。卡牌消耗以 0-3 为主。
* **Reaction Points（反应点）**：每回合 1 点（可通过属性/装备增加）。用于反击/闪避/解招。
* **Stamina（耐力/怒气）**：少量临时资源，用于发动消耗卡或祭献更强的合体。可在营地/茶馆恢复或通过特定卡牌回复。
* **牌库与抽牌**：标准抽牌机制，弃牌堆可通过“复苏”类卡加入场上单位的回收循环。鼓励“场上持久”和“手牌控制”的策略。

# 7) 叙事与 DnD 风格遭遇（战斗外的检定）

在路径事件或战斗中加入 DnD 风格的技能事件：

* 追踪伏击 → Survival 检定决定是否获得先攻或额外卡牌
* 斡旋/收买 → CHA 检定决定是否避免战斗或招募小 BOSS 的手下
* 师门试炼 → INT/DEX 联合检定解谜且会改变下一层卡池

这些非战斗检定影响后续战斗难度、卡池获得率或商店物品。

# 8) 示例卡（具体数值可调）

（数字给出便于立刻实现；调平衡时逐步调整）

1. 破山式（Attack）

   * 费用：1 Qi
   * 效果：造成 9 点伤害。若你场上有剑影类单位，额外造成 +4 伤害。

2. 剑影（Summon）

   * 费用：1 Qi
   * 效果：召唤“剑影”单位（HP 6 / ATK 4）。存在时你的攻击卡获得 +1 伤害（被动）。

3. 试探五式（Skill / Check）

   * 费用：1 Qi
   * 效果：对敌人发动 WIS 检定（DC 12）。成功：敌人下一次攻击 -2 命中并受 6 点伤害。失败：无效果且你失去 1 Reaction。

4. 闭月心法（Power）

   * 费用：2 Qi
   * 效果：每回合开始时回复 3 HP。若你持有 >1 个心法，则额外 +1 Qi（心法组套增益）。

5. 祭剑·合一（Tribute / Merge）

   * 费用：0 Qi（但需牺牲两个场上单位）
   * 效果：牺牲 2 个单位召唤“祭剑·合一”（HP 18 / ATK 14）。使用后进入冷却 3 回合。（合体需要重大代价，但瞬间改变场面）

6. 夺魂吼（Expend）

   * 费用：3 Qi（使用后剔除）
   * 效果：全场 30 点伤害，所有敌人做 CON 豁免（DC 15）成功则伤害减半；失败则额外眩晕 1 回合。

# 9) 敌人 & Boss 设计思路（示例）

* **普通敌人：流氓剑客**

  * 具有“抢占格子”的行为，会尝试冲击你的前排单位。弱点是感知低（易被 WIS 检定识破）。

* **精英敌人：毒蛛门弟子**

  * 拥有陷阱布置（消耗你的 DEX 检定来躲开），可召唤小蜘蛛（弱单位）分散你资源。

* **Boss：铁掌宗掌门（多阶段）**

  * 第一阶段：以压制为主，强制你进行 STR 豁免来避免被击倒（失败导致下一回合失去所有反应）。
  * 第二阶段（HP < 60%）：触发“狂暴”状态，攻击变为群体攻击，并在场上召唤门徒。玩家需要采用“祭献合体”或成功的 INT / WIS 检定来破除掌门的护体。
  * Boss 的关键是把检定与场上单位的互动放在核心，让玩家不能只靠纯卡伤。

# 10) 进度与永久成长（roguelike 续航）

* **单次运行内成长**：心法、武学残页、门派羁绊（相当于 Powers / Relics）会在单次 run 中持续。
* **长期解锁（meta）**：通过成功 run 解锁新的起始职业、牌、遗物和门派（比如学会“祭剑”路线，下一次跑图时有更高几率抽到祭剑系卡）。
* **营地替代物：茶馆/武林盟会**：在节点可以选择：冥想（恢复 HP、可升级一张卡），训练（小幅提升属性），也可把普通牌“锻造”为绝学（把多张卡合并为一张强卡）。
* **金钱/资源**：用“铜钱/秘籍”购买装备或付门派学徒钱获取特殊卡。

# 11) UI/交互建议（游戏体验）

* **卡牌 UI**：卡牌面下方显示触发的属性检定（例如“WIS 检定 DC12”）和是否可以“祭献/上阵”。
* **场上格子可视化**：左侧玩家 3 格, 1 后排；右侧敌方同样。拖拽卡片到格子即召唤。合体时显示被牺牲的高亮提示。
* **检定弹窗**：进行检定时弹出 d20 动画（可选择隐藏掷骰动画，若玩家喜欢更 DnD 的沉浸感则展示），显示属性修正、优势/劣势来源与结果。
* **反应快捷键**：在敌人播放动作时出现可用反应提示（例如“按 R 使用反击”），确保战斗紧张感且不拖沓。
* **叙事弹窗**：重要检定失败/成功会触发短剧情文本，增强武侠感（例如“你看穿了对手内劲的流向，一记破招化解了他全力一击！”）。

# 12) 平衡与可玩性建议（调参路线）

* 初期用小规模数值测试（例如：基础普通怪 HP 20~30，精英 60~80，Boss 200~300）。
* 重点测试循环：召唤单位是否过强（注意限制场格和召唤冷却）；祭献/合体的代价要让玩家在“牺牲现在收益”和“保留小单位长期收益”之间产生抉择。
* 检定频率与赌注：检定过多会让战斗变成掷骰游戏，过少则失去 DnD 风味。建议：每战 2~4 次重要检定（与 Boss/关键卡绑定）。
* 心法与 Qi 经济要互相制衡：持续效果不可无限堆叠（引入上限或递减效果）。

# 13) 举例完整战斗场景（流水账式示例）

你（剑宗，STR 强）遇到两个流氓与一名精英毒蛛弟子。你准备阶段选择“机动”姿态（+DEX 优势）。

1. 准备：布置“剑影”入后排（1 Qi）。
2. 行动：打出“试探五式”（1 Qi，WIS 检定 DC12）。你感知属性 +2，掷 d20 得 11 → 11+2=13 成功，敌人失去下一次攻击命中并受 6 伤。
3. 召唤：你祭出“剑影”在前排，吸引流氓注意。
4. 敌方回合：毒蛛布陷阱→你用 Reaction 点发动“翻滚”闪避（消耗 Reaction）成功躲避并触发反击，造成小额伤害。
5. 通过祭献两个小单位（牺牲剑影+另一个小召唤）你召唤“祭剑·合一”，在下一回合用消耗卡一举秒掉精英。

场内既有卡牌的组合，又有检定与反应，决策丰富且有武侠感觉。

# 14) 可选扩展（让玩法更“武侠”）

* **门派羁绊**：例如“剑宗双召”——若场上有 2 个剑影则触发门派羁绊，给主角“破风”被动。
* **声望/仇恨系统**：做过的选择（救人/杀人）会影响后续商店/门派派系对你态度。
* **修行系统（Meta）**：玩家可用长期资源提升某一属性（比如永久 +1 DEX），改变每次跑图策略。
* **多人对战/擂台**：用现有系统做 PvP 模块（卡组对卡组 + 场上单位 + 棋盘格位），非常贴合游戏王竞技感觉。
